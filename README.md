# Orbit — простір ідей

Український вебінструмент для нотаток, планів і проєктів на нескінченному полотні. Початкова дошка містить нейтральні приклади для нового проєкту.

**Опублікований сайт:** https://systemh4rd.github.io/HomeDos/

## Можливості

- Нотатки, чеклісти, посилання та файлові вкладення до 20 МБ.
- Переміщення блоків, масштабування й навігація полотном.
- Зв’язки між блоками, кілька дошок і пошук.
- Скасування останніх змін, темна та світла теми.
- Експорт та імпорт JSON разом із вкладеннями.
- Збереження прямокутного фрагмента або всієї дошки у PDF.
- Реєстрація, вхід і приватне онлайн-збереження дошок та вкладень через Supabase (потребує підключення проєкту).
- Адаптивний український інтерфейс для телефона, планшета й комп’ютера.
- Керування полотном одним або двома пальцями, великі кнопки та прокручувана панель інструментів.
- Завантаження бібліотеки PDF лише під час експорту, а бібліотеки авторизації — лише після підключення сервісу.
- Збереження масштабу під час зміни орієнтації та зручні форми над екранною клавіатурою.

## Зберігання даних

Без входу дошки зберігаються у `localStorage`, вкладення — в `IndexedDB`. Після входу простір профілю автоматично зберігається в Supabase та завантажується на інших пристроях. Дочекайтеся позначки **«Збережено онлайн»**. Локальна копія залишається при збої мережі; конфлікти між пристроями не перезаписуються автоматично. Спільного редагування в реальному часі немає. Деталі підключення й відновлення: [AUTH_SETUP.md](AUTH_SETUP.md).

## PDF-фрагменти

Натисніть **PDF** у верхній панелі, виділіть прямокутник мишею або пальцем і виберіть **Зберегти PDF**. Можна також експортувати **Усю дошку**. PDF містить вибрану область полотна без панелей сайту; він створюється на пристрої, без надсилання вмісту дошки на сервер. Вкладення відображаються як картки з назвами файлів. Текст у PDF растровий, тому не виділяється як текст.

## Реєстрація

Форми реєстрації, входу та відновлення пароля працюють через Supabase Auth після налаштування проєкту. До підключення показується повідомлення про неактивну реєстрацію. Інструкція: [AUTH_SETUP.md](AUTH_SETUP.md). Після налаштування таблиці й сховища дошки профілю зберігаються онлайн; гостьовий простір залишається локальним.

## Походження

Orbit — незалежна реалізація за мотивами концепції [Ideon](https://github.com/3xpyth0n/ideon). Це не оригінальний Ideon і не його офіційна версія. Код upstream не скопійовано. Оригінальний Ideon потребує окремого Docker-хостингу та PostgreSQL.

## GitHub Pages

Сайт не потребує компіляції. Для реєстрації використовується окремий сервіс Supabase Auth. Файли готові до публікації з каталогу `docs/`:

1. Відкрийте **Settings → Pages** у репозиторії.
2. Виберіть **Deploy from a branch**.
3. Виберіть гілку **main** і каталог **/docs**, збережіть налаштування.

Файл `docs/.nojekyll` дозволяє публікувати статичні файли без Jekyll.

## Перевірка

Перевірка синтаксису:

```sh
node --check docs/app.js
```

Окремі DOM-перевірки описані в [qa/README.md](qa/README.md). Вони перевіряють основні дії та збереження, але не замінюють візуальну перевірку в браузері.
