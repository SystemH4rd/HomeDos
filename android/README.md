# HomeDos Android 1.0.0

Android-застосунок відкриває https://systemh4rd.github.io/HomeDos/ у захищеному WebView. Це Android-оболонка вебверсії, а не окрема копія бази. Сайт і APK використовують один Supabase; увійдіть у той самий акаунт та дочекайтеся «Збережено онлайн», перш ніж переходити на інший пристрій. Гостьові дошки залишаються окремими на кожному пристрої.

Потрібні Android 8.0+ (API 26), актуальний Android System WebView / Chrome та інтернет для завантаження сайту й синхронізації. Застосунок підтримує вибір вкладень системним діалогом, збереження оригіналів/JSON/PDF через системний вибір місця, зовнішні посилання в браузері й кнопку Android «Назад». Відновлення пароля відкривається в браузері, щоб лист і PKCE-перевірка працювали в одному браузерному сеансі. Після підтвердження реєстрації в листі поверніться в APK та увійдіть паролем.

В APK немає серверних секретів. Дозвіл лише INTERNET; доступ до вибраних файлів надає системний файловий діалог. Завантаження сторонніх сторінок у головний WebView та незахищений HTTP заборонені, SSL-помилки не ігноруються, резервне копіювання даних Android вимкнено. Підтримка JavaScript та IndexedDB потрібна для самої дошки.

## Встановлення

1. Завантажте `HomeDos-1.0.0.apk` кнопкою Android APK на сайті.
2. Відкрийте файл. За потреби дозвольте браузеру встановлення застосунків із цього джерела.
3. Запустіть HomeDos, увійдіть у той самий акаунт, що й на сайті.
4. Оберіть, чи запам’ятовувати вхід на цьому пристрої. Вихід з акаунта видаляє збережену сесію.

Це пряме встановлення APK, не публікація в Google Play. Зміни вебінтерфейсу надходять разом з оновленням сайту; зміни Android-оболонки потребують нового APK.

## Збірка

Збірка без Gradle: Android platform 35, build-tools 35.0.0, Eclipse ECJ 3.39.0, Java 21, Python 3. Офіційні SDK-архіви розпаковані в `/tmp/homedos-android-sdk`:

- https://dl.google.com/android/repository/platform-35_r02.zip (SHA-1 `0bb560a90a7a2cbd0dd8348224d518b638fe7949`)
- https://dl.google.com/android/repository/build-tools_r35_linux.zip (SHA-1 `2cfaa0bbb2336e9ec18ed3ecea84fa2e2af607bc`)
- https://repo.maven.apache.org/maven2/org/eclipse/jdt/ecj/3.39.0/ecj-3.39.0.jar

```sh
bash android/build.sh
```

Можна перевизначити `HOMEDOS_ANDROID_SDK`, `HOMEDOS_SIGNING_DIR` та `HOMEDOS_APK_OUTPUT`. Стандартний результат — `/workspace/output/HomeDos-1.0.0.apk`. Скрипт перевіряє підпис APK v2/v3 та записує SHA-256. Мета — API 35; пакет `ua.homedos.app`.

Ключ підпису та пароль створюються поза репозиторієм у `/workspace/homedos-signing`. Вони потрібні для встановлення майбутніх оновлень поверх цього APK. Збережіть приватну резервну копію; не завантажуйте ключ, пароль або архів із ними в публічний репозиторій. Втрата ключа означає, що наступний APK з іншим підписом потребуватиме перевстановлення.

Перевірено компіляцію, DEX, manifest/package, підпис офіційним apksigner та JavaScript-міст збереження файлів у Chromium. Фізичний Android-пристрій та емулятор під час цієї збірки не були доступні: встановлення, системний вибір файлів і WebView на реальному телефоні потребують перевірки.
